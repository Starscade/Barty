# Barty

This is a vibe-coded remix of a personal tool I made awhile back. The name is 
taken from BART's official [anime mascot](https://www.bart.gov/news/fun/anime).
The page includes a public API key which BART provides with no strings. 
However, I'm sure they'd appreciate it if you  registered your 
[own](https://api.bart.gov/api/register.aspx).
